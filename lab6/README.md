#### Постановка задачи:

Генерация заданного числа копий указанного файла. Имена копий генерировать добавлением к имени исходного файла следующей
по порядку буквы или цифры, начиная с заданной буквы или цифры.

#### Описание работ:

Создаем функцию, которая будет принимать 4 аргумента и по ним копировать файлы. Заведем 3 массива, под разные
символы/цифры, чтобы потом перемещать указатель по ним и указывать следующий символ. Также нам надо определить, к какому
типу относится начальный символ: к букве в верхнем, нижнем регистре или цифре. Для этого пройдемся по каждому массиву и
сравним начальный символ с элементами массива. Если совпало, то запоминаем тип и индекс элемента. Далее в цикле от 0 до
n, мы будем генерировать имя файла, добавляя к нему символ из массива, который соответствует типу
начального символа. После этого копируем исходный файл с припиской символа, который мы нашли.

#### Запуск:

```commandline
./main.bash 5 example.txt a ./copies
```

Также можно посмотреть на параметры запуска:

```commandline
./main.bash
```

Вывод:

```text
Использование: ./main.bash <кол-во копий> <исходный файл> <начальный символ> <директория>
```
